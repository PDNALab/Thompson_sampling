# LBtope raw data

Linear B-cell epitope data set LBtope (Singh et al.), downloaded from <https://webs.iiitd.edu.in/raghava/lbtope>.

- `LBtope_Fixed-positive.txt`, `LBtope_Fixed-negative.txt`: 20-mers, one peptide per line (used for the figure)
- `Lbtope_variable_non-redundant-positive.txt`, `LBtope_variable_non-redundant-negative.txt`: variable length (not used for the figure)

`../../../work/cluster_lbtope.py` turns the Fixed files into `../fixed.csv`.
