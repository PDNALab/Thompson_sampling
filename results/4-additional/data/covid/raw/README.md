# Peptide array raw data (not in git, 178 MB)

`IgG_aggregate_file_covid_pub.csv`: SARS-CoV-2 / coronavirus peptide microarray, plasma IgG signal of 132 samples
(Mishra et al., Communications Biology 2021). Download from Dryad: <https://doi.org/10.5061/dryad.2547d7wnz> (CC0)
and save the file in this folder.

`../../../work/build_library.py` turns it into `../library.csv`.
